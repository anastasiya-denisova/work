## 🚀 Запуск автотестов и генерация отчетов через Allure

В проекте настроен автоматический запуск Postman-коллекции с помощью консольной утилиты **Newman** и выгрузка результатов в профессиональный отчет **Allure Report**.

### 📋 Предварительные требования
Для работы тестов на вашем компьютере должны быть установлены:
1. [Node.js](https://nodejs.org) (версии 16 и выше).
2. Системный пакет Allure CLI. На macOS он устанавливается через терминал командой: `brew install allure`.

---

### 🛠️ Инструкция по пошаговому запуску

Откройте ваш терминал и выполните следующие команды по очереди:

1. **Перейдите в рабочую папку проекта на Рабочем столе:**
   ```bash
   cd Desktop/work
   ```

2. **Установите утилиту Newman глобально в систему (если не установлена):**
   ```bash
   npm install -g newman
   ```

3. **Установите плагин-репортер Allure для Newman:**
   ```bash
   npm install -g newman-reporter-allure
   ```

4. **Запустите тестирование коллекции Postman:**
   ```bash
   newman run Dummy.postman_collection.json -r allure
   ```
   *После выполнения этой команды в папке автоматически создадутся сырые файлы результатов в директории `allure-results`.*

5. **Сгенерируйте и откройте интерактивный отчет Allure в браузере:**
   ```bash
   allure serve allure-results
   ```

---

### 💡 Полезный лайфхак
Если вы хотите одновременно видеть ход выполнения тестов прямо в консоли и при этом записывать результаты для Allure, используйте комбинированный запуск:
```bash
newman run Dummy.postman_collection.json -r cli,allure
```
